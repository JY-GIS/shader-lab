# Shader Lab

以 CesiumJS 场景为主要实验环境的 Shader / GLSL 学习仓库。

## 开发环境

- Vue 3
- TypeScript
- Vite
- CesiumJS
- GLSL

本地环境：Node.js v24.18.0、npm 11.16.0。

## 运行

- `npm run dev`：启动本地开发环境
- `npm run build`：检查类型并构建项目

## 学习进度

- Shader 01：Fabric 材质、颜色与透明度
- Shader 02：纹理坐标与颜色渐变
- Shader 03：`step()`、`smoothstep()` 与颜色边界
- Shader 04：向量距离、圆形遮罩与柔和边缘
- Shader 05：`sin()`、`cos()`、弧度与静态周期颜色
- Shader 06：Fabric Uniform、时间驱动条纹与事件清理
- Shader 07：`fract()`、`abs()`、动态扩散圆环与 Alpha 淡出
